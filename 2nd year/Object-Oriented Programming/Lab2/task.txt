
Task 1: Fundamental Control Structures
Write separate C++ programs for each of the following problems.
(a) Sum of Floating-Point Numbers
Write a program that:
 Prompts the user to enter five floating-point numbers.
 Uses a loop to calculate their sum.
 Displays the result clearly labeled.
Requirement: The solution must use an iterative control structure.
(b) Smallest Integer Finder
Write a program that:
 Prompts the user to enter five integers.
 Determines the smallest value among them.
 Displays the smallest value clearly labeled.
Requirement: The solution must use conditional statements.
(c) Power Calculation
Write a program that:
 Prompts the user to enter two integers: n and m.
 Computes n^m using an iterative approach (without using built-in power functions).
 Displays the result clearly labeled.
Requirement: The solution must use a loop-based implementation.


Task 2: Menu-Driven Arithmetic Program (Numeric Options)
Write a C++ program that implements a menu-driven calculator.
The program must:
1. Display the following options:
1 – Add
2 – Subtract
3 – Multiply
4 – Quit
2. Prompt the user to select an option between 1 and 4.
3. Use a switch statement to handle the selection.
4. For options 1–3:
 Prompt the user to enter two numeric values.
 Perform the selected operation.
 Display the result clearly labeled.
5. Terminate when the user selects option 4.
Requirement: The program must continue running until the user chooses to quit.
